# Security Policy

## Supported Versions

Security fixes are provided for the latest released version of Mobile Emulator Manager.

## Scope

This policy covers the VS Code extension in this repository, including command construction, Webview UI, configuration handling, and installation of apps on local emulators.

The Android SDK, Android Emulator, Xcode, iOS Simulator, and emulator images are maintained by their respective vendors and are outside this repository's scope. Vulnerabilities in how this extension invokes or handles those tools remain in scope.

## Reporting a Vulnerability

Please do not report suspected vulnerabilities in a public GitHub issue. Instead, use [GitHub's private vulnerability reporting](https://github.com/noritaka1166/vscode-mobile-emulator-manager/security/advisories/new).

Include the affected extension version, reproduction steps, impact, and any proof of concept necessary to validate the report. The maintainer will assess the report and coordinate a fix and disclosure as appropriate.
