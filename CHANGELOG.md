# Changelog

All notable changes to "Mobile Emulator Manager" will be documented in this file.

## [0.1.0] - 2026-06-07

### Added
- Sidebar view to manage iOS Simulators and Android Emulators
- Smart grouping by OS version (e.g., iOS 26.0, Android 16 (API 36))
- Start / Stop emulators with a single click
- Progress indicator while waiting for Android emulators to boot
- Copy UDID for iOS Simulators via right-click context menu
- Auto-refresh of device status after start/stop operations
